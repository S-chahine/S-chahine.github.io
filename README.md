
# Personal Developer Portfolio

A responsive personal developer portfolio built with **React**, **TypeScript**, and **Vite** to showcase my projects, technical skills, and development experience.

🔗 **Live Demo:** [View Portfolio](https://s-chahine.github.io/)

## Overview

This portfolio highlights my work as a full-stack developer, including selected projects, technical skills, and background. The website is designed to be clean, responsive, and easy to navigate across desktop and mobile devices.

## Features

- Hero section with a short introduction and call to action
- Projects section with links to live demos and GitHub repositories
- Skills section highlighting my technical stack
- About section describing my background and interests
- Fully responsive layout for desktop, tablet, and mobile screens

## Tech Stack

**Frontend:** React, TypeScript, Vite  
**Styling:** Tailwind CSS  
**Icons / UI:** Lucide React, React Icons  
**Deployment:** GitHub Pages  

## Purpose

This project was created to present my development experience, demonstrate my frontend skills, and provide employers with a quick way to view my work and contact information.

## Running the Project

1. Clone the repository
2. Install dependencies: npm install
3. Run development server: npm run dev
4. Open http://localhost:8080 in your browser
